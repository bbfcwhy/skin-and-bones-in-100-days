Project Brief v0.1

100 天減脂追蹤 App

把「今天要做什麼」、「我做了多少」與「這週需不需要調整」放在同一個地方。第一版先服務你自己，連續使用 100 天後，再決定要不要變成公開產品。

推薦平台iPhone 原生 App
第一位使用者威爾自己
資料策略本機優先＋iCloud
MVP 時程約 6 到 8 週
GitHubPrivate repo

Product position

不是另一個算熱量工具

產品核心是把個人計畫變成每天可執行、可記錄、可調整的回饋循環。

我的推薦：先做 iOS 個人版。你的體重、腰圍、步數與運動紀錄都集中在 iPhone 使用情境，先用 SwiftUI 與本機資料庫把體驗做好，比一開始就做帳號、後端與訂閱風險低很多。
1

執行問題

計畫散在文章、表格與記憶裡，每天要先想一次才能開始。

2

記錄問題

勾選、體重、腰圍、熱量、步數與訓練成績沒有同一條時間線。

3

調整問題

數字有變化時，不知道是單日水分波動，還是真的該改熱量與訓練。

Scope

MVP 範圍

第一版只做「每天會開」與「每週會看」的功能。

P0，MVP 必做

  • 個人設定與 100 天目標
  • 依運動日自動切換熱量與份量
  • 今日 Checklist 與數值輸入
  • 一週運動飲食表
  • 體重、腰圍、肌力趨勢
  • 每週檢討與 ±150 kcal 調整
  • JSON / CSV 匯出與備份

P1，自用穩定後

  • HealthKit 讀取步數、體重與睡眠
  • 本地通知與補充品提醒
  • 自訂運動 A / B 與食物快速模板
  • 計畫版本與改動紀錄
  • 桌面 Widget

不做清單

  • AI 食物照片估熱量
  • 社群、排行榜與加好友
  • 第一版就做訂閱付費
  • 通用教練後台
  • 複雜食物資料庫
  • 自動下醫療診斷

Information architecture

5 個主畫面

主導覽保持少，今天頁是每次開 App 的起點。

01

今天

當日熱量、餐點、運動、飲水與輸入欄位。

02

本週

7 天行程、完成率、週任務與補做狀態。

03

趨勢

7 天平均體重、腰圍、步數、肌力與完成率。

04

計畫

100 天目標、運動模板、飲食規則與每週調整紀錄。

05

設定

進食窗、水杯、補充品、資料匯出、回饋與關於。

Core loop

核心使用流程

設定目標
輸入體重、窗口、設備與偏好。
生成計畫
建立 100 天、每週運動與份量。
今日執行
勾選、輸入並完成運動。
週日檢討
看 7 天平均、腰圍與力量。
微調下週
維持，或以 150 kcal 為單位調整。

Data

資料模型

一開始就把「計畫」與「實際紀錄」分開，以後改計畫才不會覆寫過去的資料。

實體用途核心欄位資料保護
UserProfile個人預設目標、進食窗、水杯、補充品、設備只修改未來計畫
Plan / DayPlan計畫規則日期、運動類型、熱量、份量、Checklist 模板計畫保留版本
DailyLog每日實際勾選、熱量、蛋白質、步數、水、睡眠不因新計畫重生
ExerciseLog運動成績動作、組數、重量、次數、距離、時間保留原始值
Measurement身體趨勢體重、腰圍、體脂、內臟脂等級標註來源與時間
WeeklyReview調整記錄7 天平均、差值、疲勞、力量、熱量改動每次調整可追溯

Definition of done

驗收條件

  • 今天所有勾選與數字在關閉、重開 App 後仍存在。
  • 跑步、肌力、恢復日會顯示正確熱量與熟重澱粉。
  • Day 1、Day 100 與時區邊界的挑戰日數無誤。
  • 7 天平均不會把未記錄日當成 0 kg。
  • 新版計畫不會覆寫舊的 DailyLog 與 Measurement。
  • 匯出後能還原等量資料，並完成一次實際復原測試。
  • iCloud 離線寫入與回線合併不造成紀錄消失。
  • 健康數據一律先取得權限，拒絕後主要功能仍可手動使用。

Risks

三個最大風險

記錄負擔過高

每天要填太多會放棄。原則是能勾就不打字，能從 HealthKit 讀就不重複填。

調整得太積極

單日體重不觸發改計畫。只用 7 天平均，且至少連續 2 週才改 150 kcal。

健康資料遺失

資料模型只擴張不收縮，每次 migration 前先備份，並保留 JSON / CSV 匯出。

Technical basis

官方技術依據

  • Apple：用 SwiftData 與 CloudKit 同步資料，需 iCloud 與 Background Modes 能力，而且 CloudKit 正式 schema 應以可擴張方式設計。
  • Apple HealthKit，可在用戶授權後取得步數、體重、腰圍、睡眠與運動資料。
  • Apple：排程本地通知，適合設定每日 Checklist、運動與補充品提醒。
